# Merchant Onboarding Guide

## Setup Checklist
1. **Register** — Create owner account via the Merchant Portal
2. **Profile** — Set cafe name, category, timezone, currency
3. **Menu** — Add products with prices, categories, and options
   - Use the Menu Import Wizard to bulk-import via CSV/Excel/OCR
4. **Inventory** — Add stock items with minimum thresholds
5. **Recipes** — Link products to inventory items (quantities per serving)
6. **Taxes** — Configure applicable tax rates
7. **Payment Methods** — Enable CASH, CARD, or other methods
8. **Staff** — Register employees with roles and login codes
9. **Branch** — Set operating hours and active status

## Go Live
- Verify menu appears in customer-facing channels
- Place a test order through Telegram
- Confirm receipt prints (if printer configured)
- Monitor orders in real-time dashboard

## Daily Operations
- Open/close branch each day
- Monitor inventory levels (low-stock alerts)
- Review sales and profit reports in Owner Copilot
- Respond to customer messages via Merchant Communication Hub
