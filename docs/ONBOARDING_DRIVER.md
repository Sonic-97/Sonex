# Driver Onboarding Guide

## Setup
1. Install Driver PWA from the link provided by your cafe
2. Log in with your staff login code
3. Enable location permissions for accurate dispatch

## Receiving Orders
- New order notifications appear in real-time
- You have 60 seconds to accept an order
- If declined, order is re-dispatched to next available driver

## Delivery Flow
1. Accept order → view customer address & items
2. Mark "Picked Up" when you collect from merchant
3. Mark "Delivered" when order reaches customer
4. Payment confirmation (CASH on delivery only)

## Tips
- Keep the app open during your shift
- Mark yourself available/offline via the toggle
- Contact merchant via in-app chat for address issues
